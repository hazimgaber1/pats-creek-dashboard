# Pat's Creek Monitor

Prototype remote monitoring dashboard for Pat's Creek Flow Monitoring, part of an engineering project to mitigate flooding on Pat's Creek in the Town of Peace River, Alberta. By HSMG.

Stations and equipment follow the Pat's Creek Flow Monitoring detailed engineering drawings (Sameng Inc., Issued for Construction, Revision 0, July 15, 2026).

- Four stations from the IFC drawing set: Upstream Inlet, In-Line Pipe 2, In-Line Pipe 1, Downstream Outlet
- Water level, flow and velocity history, site schematic, station battery and signal health
- Camera feed panels for the Upstream Inlet and Downstream Outlet cameras
- Live Peace River weather (Open-Meteo)
- Flood watch and flood alarm levels per structure
- Alert settings (thresholds, contacts, text / email / push) with message previews

**All readings and video are simulated.** No alerts are sent. Alert settings save only in the visitor's browser on this hosted copy.
